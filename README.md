# Travel Mentor

Travel Mentor is a next-generation travel assistance platform that focuses on providing a human-centered travel experience by connecting travelers with experienced local mentors.

## 🛠️ Technology Stack
- **Framework**: Next.js (App Router)
- **Language**: TypeScript
- **Styling**: CSS Modules (Custom Aurora Glass design system)
- **Backend**: Firebase (Authentication & Firestore)

## ✨ Core Features
- **Travel Mentorship**: Connect with local experts and experienced travelers for personalized guidance.
- **Safety-Focused Travel**: Mentor verification and tailored safety support.
- **Travel Utility Toolkit**: Offline maps, translator, and safety advisories.
- **Dynamic User Dashboard**: Track your upcoming trips and mentor messages in real-time.

## 💻 Development

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## 📂 Project Structure
- `src/app`: Next.js App Router pages and layouts.
- `src/components`: Reusable Aurora Glass UI components.
- `src/lib`: Firebase configuration and utilities.
- `legacy_assets`: Original hackathon HTML/JS files for reference.
